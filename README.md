Once you click the link, you'll land on the official download page. Look for the green "Code" button and click it, then select "Download ZIP" from the dropdown menu. Your browser will save a compressed folder to your computer – usually in your "Downloads" folder.

### Step 3: Unzip the Folder

Navigate to your Downloads folder and find the file named `server-api-main.zip`. Right-click it and choose "Extract All" (Windows will walk you through this). You'll end up with a new folder called `server-api-main`.

Open the extracted folder and double-click the file named `start-server.bat`. This will open a black window (command prompt) – that's normal! Leave it open; it's your server running. Then open your web browser and go to `http://localhost:3000`. You'll see your server-api console!

## 📖 How to Use server-api

### Your First Launch
1. Double-click `start-server.bat`
2. Wait for "Server ready on port 3000" message
3. Open your browser to `http://localhost:3000`
4. You'll see the welcome screen with a pairing code

### Pairing Your First Device
1. On your second device, open its browser
2. Go to `http://[your-computer-ip]:3000`
3. Enter the 6-digit code shown on your main screen
4. Click "Pair Device" – done!

### Managing Agents
- **Claude Code:** Click "Agents" in the left menu, then "Add Agent" and select Claude Code
- **Codex:** Same process – just pick Codex from the dropdown
- **DeepSeek Harness:** Select it from the list and follow the prompts

### Sending Commands
Use the command bar at the top of the console. Type any instruction and press Enter. The server relays it to the appropriate agent and shows the response in real time.

## ❓ Troubleshooting

### The window closes immediately
Make sure you're running `start-server.bat` and not a different file. If it still closes, check that you have administrator rights.

### I can't connect from another device
Your firewall might be blocking the connection. Allow Node.js through Windows Firewall when prompted, or add an exception for port 3000.

### The console looks strange in my browser
Try a different browser, or clear your cache. server-api works best in Chrome or Edge.

### I forgot my pairing code
Restart the server. A new code will appear in the command window every time.
